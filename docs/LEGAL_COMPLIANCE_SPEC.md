## 🛠️ 4. ארכיטקטורת נתונים ויכולת עריכה מפאנל הניהול

כדי לעמוד בדרישת המערכת לאפשר **עריכה קלה מפאנל הניהול**, כלל התוכן המשפטי מאורגן במבנה מודולרי:
1. **קובץ נתוני בסיס סטטי (`src/data/legalContent.js`)**: מכיל את כלל הטקסטים המלאים והתקניים, מחולק לפי מזהים (`terms`, `cancellation`, `warranty`, `privacy`, `accessibility`).
2. **מנגנון Override ב-LocalStorage**: פאנל הניהול (Admin CMS) יכול לשמור גרסאות מותאמות אישית של כל מסמך ב-LocalStorage תחת המפתח `mishkan_legal_overrides`.
3. **ייצוא כפול (JSON + JS)**: תמיכה בקריאה דינמית ב-React וייצוא כ-JSON לצורכי גיבוי ושחזור.

## 🔒 5. סיכום הנחיות יישום למפתחים
1. **אין להסתיר אותיות קטנות**: כל המידע הצרכני (מחירים, משלוחים, דמי ביטול) מופיע בפונט קריא וניגודי.
2. **טופס ביטול קל ונגיש**: קישור ישיר בפוטר שאינו דורש הרשמה או סיסמה לצורך הגשת בקשת ביטול.
3. **חובת סימון בתשלום**: לאפשר כפתור "שלם עכשיו ב-Bit" אך ורק לאחר שסומנה תיבת ההסכמה לתקנון.
4. **יידוע בטופס הפרטים**: מתחת לשדות שם/טלפון/כתובת תופיע הערת יידוע משפטית מקוצרת המפנה למדיניות הפרטיות.
